- **目标用户**: 6-12岁儿童及打字学习者

## 🎯 一、游戏概述

### 1.1 游戏简介
一款支持多人实时对战的打字竞速游戏，玩家通过快速准确地输入单词来推进自己的赛车，与其他玩家进行实时竞技。游戏结合了教育性和趣味性，帮助玩家提升打字速度和准确度。

### 1.2 核心玩法
- **实时对战**: 最多4名玩家同时在线竞技
- **单词挑战**: 依次输入20个单词完成比赛
- **即时反馈**: 实时显示排名和进度
- **社交互动**: 房间系统，支持好友组队

### 1.3 游戏特色
- ✅ 实时同步：毫秒级的进度同步
- ✅ 公平竞技：所有玩家使用相同的单词列表
- ✅ 儿童友好：简单明了的操作界面
- ✅ 无需下载：基于Web的跨平台体验

## 🏗️ 二、技术架构

### 2.1 技术选型

#### 前端技术栈
- **HTML5 + CSS3**: 游戏界面
- **JavaScript (ES6+)**: 游戏逻辑
- **WebSocket**: 实时通信
- **LocalStorage**: 本地数据存储

#### 后端技术栈（简化方案）
**Node.js + Socket.io 纯内存方案**
- **Node.js + Express**: HTTP服务和路由
- **Socket.io**: WebSocket实时通信
- **内存存储**: 房间和玩家数据直接存储在内存中
- **无需数据库**: 简化部署和维护
- 优点：
  - 极简架构，易于开发和部署
  - 无外部依赖，降低成本
  - 快速启动，适合小规模应用
- 限制：
  - 服务器重启数据丢失（可接受，因为房间是临时的）
  - 单机部署，不支持水平扩展
  - 适合100个以内同时在线房间

3. 可选配置：

**房间号生成规则：**
```javascript
function generateRoomId() {
    const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
    let roomId = '';
    for (let i = 0; i < 6; i++) {
        roomId += chars.charAt(Math.floor(Math.random() * chars.length));
    }
    return roomId;
}
```

#### 3.3.3 单词输入系统

**输入区域：**

  - ✅ 正确前缀 → 绿色高亮

**单词验证逻辑：**
```javascript
function validateInput(input, targetWord) {
    input = input.toLowerCase().trim();
    targetWord = targetWord.toLowerCase();
    
    if (input === targetWord) {
        return { status: 'complete', match: true };
    } else if (targetWord.startsWith(input)) {
        return { status: 'typing', match: true };
    } else {
        return { status: 'error', match: false };
    }
}
```

**防作弊机制：**
- 检测输入速度异常（每个字母间隔<30ms视为异常）

## 🔒 七、安全与防作弊

### 7.1 防作弊措施

1. **输入速度检测**
   - 每个字符间隔最小阈值（30ms）
   - 超过阈值标记异常

2. **复制粘贴检测**
   - 监听 `paste` 事件
   - 禁止粘贴或标记警告

3. **服务器端验证**
   - 客户端提交单词完成 → 服务器验证
   - 检查时间合理性
   - 检查单词正确性

4. **房间权限控制**
   - 只有房主能开始游戏
   - 只有在房间内的玩家能提交进度

### 7.2 数据安全

1. **输入验证**
   - 昵称长度和字符限制
   - 房间号格式验证
   - 消息内容过滤（防XSS）

2. **频率限制**
   - 创建房间：每分钟最多3次
   - 加入房间：每分钟最多10次
   - 消息发送：每秒最多5条

#### 7.3.2 房间过期自动清理

**实现机制：**
```javascript
// 创建房间时记录创建时间
const room = {
    roomId: "ABC123",
    createdAt: Date.now(),
    expiresAt: Date.now() + (60 * 60 * 1000), // 1小时后过期
    // ... 其他数据
};

// 定时清理任务（每5分钟执行一次）
setInterval(() => {
    const now = Date.now();
    const roomsToDelete = [];
    
    for (const [roomId, room] of rooms.entries()) {
        if (now > room.expiresAt) {
            // 通知房间内所有玩家
            io.to(roomId).emit('ROOM_EXPIRED', {
                message: '房间已过期，即将关闭'
            });
            roomsToDelete.push(roomId);
        }
    }
    
    // 删除过期房间
    roomsToDelete.forEach(roomId => {
        rooms.delete(roomId);
        console.log(`房间 ${roomId} 已过期删除`);
    });
}, 5 * 60 * 1000); // 每5分钟检查一次
```

**检测离线的方式：**

1. **Socket断开连接（主动离开/网络中断）**

2. **心跳超时检测（可选）**

```javascript
// 玩家每30秒发送一次心跳
const playerLastSeen = new Map();

// 检测超过60秒未心跳的玩家
```

**离线处理策略：**

**情况1: 等待状态离线（未开始游戏）**
```javascript
if (room.status === 'waiting') {
    // 立即从房间移除
    room.players = room.players.filter(p => p.playerId !== playerId);
    
    // 通知其他玩家
    io.to(roomId).emit('PLAYER_LEFT', {
        playerId,
        nickname: player.nickname,
        reason: 'offline'
    });
    
    // 如果是房主离线，转让房主权限
    if (room.hostId === playerId && room.players.length > 0) {
        room.hostId = room.players[0].playerId;
        room.players[0].isHost = true;
        io.to(roomId).emit('HOST_TRANSFERRED', {
            newHostId: room.hostId
        });
    }
    
    // 房间空了就删除
    if (room.players.length === 0) {
        rooms.delete(roomId);
    }
}
```

**情况2: 游戏进行中离线**
```javascript
if (room.status === 'playing') {
    // 标记为离线，但保留数据（给重连机会）
    const player = room.players.find(p => p.playerId === playerId);
    if (player) {
        player.status = 'offline';
        player.offlineAt = Date.now();
    }
    
    // 通知其他玩家
    io.to(roomId).emit('PLAYER_OFFLINE', {
        playerId,
        nickname: player.nickname
    });
    
    // 5分钟后仍未重连，视为弃赛
    setTimeout(() => {
        const currentPlayer = room.players.find(p => p.playerId === playerId);
        if (currentPlayer && currentPlayer.status === 'offline') {
            // 标记为弃赛
            currentPlayer.status = 'abandoned';
            room.gameState.playerProgress[playerId].abandoned = true;
            
            io.to(roomId).emit('PLAYER_ABANDONED', {
                playerId,
                nickname: currentPlayer.nickname
            });
        }
    }, 5 * 60 * 1000);
}
```

**情况3: 游戏结束后离线**
```javascript
if (room.status === 'finished') {
    // 直接移除，不影响游戏结果
    room.players = room.players.filter(p => p.playerId !== playerId);
    
    // 房间空了就删除
    if (room.players.length === 0) {
        rooms.delete(roomId);
    }
}
```

**断线重连机制（可选）：**
```javascript
// 客户端保存房间ID和昵称
localStorage.setItem('lastRoomId', roomId);
localStorage.setItem('lastNickname', nickname);

// 重新连接时尝试恢复

    if (lastRoomId) {
        socket.emit('RECONNECT', {
            roomId: lastRoomId,

            previousSocketId: socket.id // 无法获取旧ID，只能重新加入
        });
    }
});

// 服务器处理重连

    const room = rooms.get(data.roomId);
    if (room && room.status === 'playing') {
        // 允许观战模式

            room,
            message: '游戏进行中，您可以观战'
        });
    }
});
```

**最佳实践建议：**
1. ⚡ 等待状态离线 → 立即移除
2. 🎮 游戏进行中离线 → 保留5分钟，给重连机会
3. 🏆 游戏结束后离线 → 直接移除
4. 👑 房主离线 → 自动转让给第一个玩家
5. 🏠 房间空了 → 立即删除

```javascript
const socketIO = require('socket.io');
const cors = require('cors');

const app = express();
const server = http.createServer(app);
const io = socketIO(server, {
    cors: {
        origin: "*",
        methods: ["GET", "POST"]
    }
});

app.use(cors());
app.use(express.json());

// ============ 内存数据存储 ============
const rooms = new Map();        // 存储所有房间 {roomId: roomData}
const players = new Map();      // 存储所有在线玩家 {socketId: playerData}

// ============ 工具函数 ============

// 生成6位房间号
function generateRoomId() {
    const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
    let roomId = '';
    for (let i = 0; i < 6; i++) {
        roomId += chars.charAt(Math.floor(Math.random() * chars.length));
    }
    // 确保房间号唯一
    if (rooms.has(roomId)) {
        return generateRoomId();
    }
    return roomId;
}

// 生成单词列表
function generateWords(difficulty, count) {
    const wordBank = {
        easy: ['cat', 'dog', 'sun', 'run', 'fun', 'hat', 'pen', 'cup', 'fox', 'box'],
        medium: ['apple', 'happy', 'water', 'hello', 'world', 'house', 'mouse', 'bread', 'cloud', 'tiger'],
        hard: ['computer', 'rainbow', 'elephant', 'butterfly', 'mountain', 'sunshine', 'playground', 'wonderful', 'keyboard', 'adventure']
    };
    
    const words = [];
    const bank = wordBank[difficulty] || wordBank.medium;
    
    for (let i = 0; i < count; i++) {
        words.push(bank[Math.floor(Math.random() * bank.length)]);
    }
    
    return words;
}

// ============ 房间清理任务 ============
// 每5分钟清理过期房间
setInterval(() => {
    const now = Date.now();
    const expiredRooms = [];
    
    rooms.forEach((room, roomId) => {
        if (now > room.expiresAt) {
            // 通知房间内所有玩家
            io.to(roomId).emit('ROOM_EXPIRED', {
                message: '房间已过期（超过1小时），将自动关闭'
            });
            expiredRooms.push(roomId);
        }
    });
    
    // 删除过期房间
    expiredRooms.forEach(roomId => {
        rooms.delete(roomId);
        console.log(`🗑️  房间 ${roomId} 已过期删除`);
    });
    
    if (expiredRooms.length > 0) {
        broadcastRoomList();
    }
}, 5 * 60 * 1000); // 每5分钟

// 广播房间列表更新
function broadcastRoomList() {
    const availableRooms = Array.from(rooms.values())
        .filter(room => room.status === 'waiting')
        .map(room => ({
            roomId: room.roomId,
            roomName: room.roomName,
            hostName: room.hostName,
            playerCount: room.players.length,
            maxPlayers: room.maxPlayers,
            difficulty: room.difficulty,
            createdAt: room.createdAt
        }));
    
    io.emit('ROOM_LIST_UPDATE', { rooms: availableRooms });
}

// ============ Socket.io 事件处理 ============
io.on('connection', (socket) => {
    const playerId = socket.id; // 使用socket.id作为玩家ID
    console.log('✅ 玩家连接:', playerId);
    
    // 添加到在线玩家列表
    players.set(playerId, {
        playerId,
        nickname: '',
        roomId: null,
        connectedAt: Date.now()
    });
    
    // 1. 创建房间
    socket.on('CREATE_ROOM', async (data) => {
        try {
            const room = await roomManager.createRoom({
                hostId: socket.id,
                nickname: data.nickname,
                roomName: data.roomName || `${data.nickname}的房间`,
                maxPlayers: data.maxPlayers || 4,
                difficulty: data.difficulty || 'medium'
            });
            
            socket.join(room.roomId);
            playerManager.addPlayer(socket.id, data.nickname, room.roomId);
            
            socket.emit('ROOM_CREATED', { 
                success: true, 
                roomId: room.roomId, 
                room 
            });
            
            // 广播房间列表更新
            io.emit('ROOM_LIST_UPDATE', { 
                rooms: await roomManager.getAvailableRooms() 
            });
        } catch (error) {
            socket.emit('ERROR', { 
                code: 'CREATE_ROOM_FAILED', 
                message: error.message 
            });
        }
    });
    
    // 2. 获取房间列表
    socket.on('GET_ROOM_LIST', async () => {
        const rooms = await roomManager.getAvailableRooms();
        socket.emit('ROOM_LIST_UPDATE', { rooms });
    });
    
    // 3. 加入房间
    socket.on('JOIN_ROOM', async (data) => {
        try {
            const room = await roomManager.getRoom(data.roomId);
            
            if (!room) {
                throw new Error('房间不存在');
            }
            
            if (room.players.length >= room.maxPlayers) {
                throw new Error('房间已满');
            }
            
            if (room.status !== 'waiting') {
                throw new Error('游戏已开始');
            }
            
            await roomManager.addPlayerToRoom(data.roomId, {
                playerId: socket.id,
                nickname: data.nickname,
                ready: false,
                laneIndex: room.players.length
            });
            
            socket.join(data.roomId);
            playerManager.addPlayer(socket.id, data.nickname, data.roomId);
            
            const updatedRoom = await roomManager.getRoom(data.roomId);
            
            // 通知房间内所有人
            io.to(data.roomId).emit('PLAYER_JOINED', {
                player: {
                    playerId: socket.id,
                    nickname: data.nickname
                },
                room: updatedRoom
            });
            
            // 广播房间列表更新
            io.emit('ROOM_LIST_UPDATE', { 
                rooms: await roomManager.getAvailableRooms() 
            });
        } catch (error) {
            socket.emit('ERROR', { 
                code: 'JOIN_ROOM_FAILED', 
                message: error.message 
            });
        }
    });
    
    // 4. 准备/取消准备
    socket.on('TOGGLE_READY', async (data) => {
        try {
            await roomManager.togglePlayerReady(data.roomId, socket.id);
            const room = await roomManager.getRoom(data.roomId);
            
            io.to(data.roomId).emit('READY_STATUS_CHANGED', {
                playerId: socket.id,
                room
            });
        } catch (error) {
            socket.emit('ERROR', { 
                code: 'TOGGLE_READY_FAILED', 
                message: error.message 
            });
        }
    });
    
    // 5. 开始游戏（房主）
    socket.on('START_GAME', async (data) => {
        try {
            const room = await roomManager.getRoom(data.roomId);
            
            // 验证是否为房主
            if (room.hostId !== socket.id) {
                throw new Error('只有房主可以开始游戏');
            }
            
            // 检查所有玩家是否准备
            const allReady = room.players
                .filter(p => p.playerId !== room.hostId)
                .every(p => p.ready);
            
            if (!allReady && room.players.length > 1) {
                throw new Error('还有玩家未准备');
            }
            
            // 3秒倒计时
            for (let i = 3; i > 0; i--) {
                io.to(data.roomId).emit('GAME_COUNTDOWN', { countdown: i });
                await new Promise(resolve => setTimeout(resolve, 1000));
            }
            
            // 生成单词列表
            const words = gameManager.generateWords(room.difficulty, 20);
            const startTime = Date.now();
            
            await roomManager.startGame(data.roomId, words, startTime);
            
            io.to(data.roomId).emit('GAME_START', {
                words,
                startTime
            });
            
            // 广播房间列表更新
            io.emit('ROOM_LIST_UPDATE', { 
                rooms: await roomManager.getAvailableRooms() 
            });
        } catch (error) {
            socket.emit('ERROR', { 
                code: 'START_GAME_FAILED', 
                message: error.message 
            });
        }
    });
    
    // 6. 更新游戏进度
    socket.on('UPDATE_PROGRESS', async (data) => {
        try {
            const room = await roomManager.getRoom(data.roomId);
            
            if (room.status !== 'playing') {
                return;
            }
            
            // 防作弊验证
            const isValid = gameManager.validateProgress(
                data.completedWords,
                data.startTime,
                data.correctCount,
                data.wrongCount
            );
            
            if (!isValid) {
                socket.emit('ERROR', {
                    code: 'INVALID_PROGRESS',
                    message: '检测到异常行为'
                });
                return;
            }
            
            // 更新进度
            await roomManager.updatePlayerProgress(data.roomId, socket.id, {
                completedWords: data.completedWords,
                correctCount: data.correctCount,
                wrongCount: data.wrongCount,
                currentWordIndex: data.currentWordIndex
            });
            
            // 计算排名
            const rankings = await gameManager.calculateRankings(data.roomId);
            
            // 广播进度更新
            io.to(data.roomId).emit('PROGRESS_UPDATE', {
                playerId: socket.id,
                progress: data,
                rankings
            });
        } catch (error) {
            console.error('更新进度失败:', error);
        }
    });
    
    // 7. 完成游戏
    socket.on('FINISH_GAME', async (data) => {
        try {
            const finishTime = Date.now();
            const room = await roomManager.getRoom(data.roomId);
            const startTime = room.gameState.startTime;
            const totalTime = finishTime - startTime;
            
            // 计算统计数据
            const stats = {
                totalTime,
                correctCount: data.correctCount,
                wrongCount: data.wrongCount,
                accuracy: Math.round((data.correctCount / (data.correctCount + data.wrongCount)) * 100),
                wpm: Math.round((data.correctCount / (totalTime / 1000)) * 60)
            };
            
            // 记录完成信息
            const rank = await roomManager.recordFinish(data.roomId, socket.id, {
                finishTime,
                stats
            });
            
            // 通知该玩家
            socket.emit('PLAYER_FINISHED', {
                rank,
                stats
            });
            
            // 广播给房间内所有人
            io.to(data.roomId).emit('PLAYER_FINISHED_BROADCAST', {
                playerId: socket.id,
                rank,
                stats
            });
            
            // 检查是否所有人都完成了
            const allFinished = await roomManager.checkAllFinished(data.roomId);
            if (allFinished) {
                const results = await gameManager.getGameResults(data.roomId);
                io.to(data.roomId).emit('GAME_END', { results });
                
                // 5秒后重置房间
                setTimeout(async () => {
                    await roomManager.resetRoom(data.roomId);
                    const resetRoom = await roomManager.getRoom(data.roomId);
                    io.to(data.roomId).emit('ROOM_RESET', { room: resetRoom });
                }, 5000);
            }
        } catch (error) {
            console.error('完成游戏失败:', error);
        }
    });
    
    // 8. 离开房间
    socket.on('LEAVE_ROOM', async (data) => {
        await handlePlayerLeave(socket.id, data.roomId);
    });
    
    // 9. 心跳检测
    socket.on('HEARTBEAT', (data) => {
        socket.emit('HEARTBEAT_ACK', { serverTime: Date.now() });
        playerManager.updateLastSeen(socket.id);
    });
    
    // 10. 断开连接
    socket.on('disconnect', async () => {
        console.log('玩家断开:', socket.id);
        const player = await playerManager.getPlayer(socket.id);
        if (player && player.roomId) {
            await handlePlayerLeave(socket.id, player.roomId);
        }
        playerManager.removePlayer(socket.id);
    });
});

// 处理玩家离开
async function handlePlayerLeave(playerId, roomId) {
    try {
        const room = await roomManager.getRoom(roomId);
        if (!room) return;
        
        await roomManager.removePlayerFromRoom(roomId, playerId);
        
        // 通知房间内其他人
        io.to(roomId).emit('PLAYER_LEFT', {
            playerId,
            room: await roomManager.getRoom(roomId)
        });
        
        // 如果房主离开，转让房主或关闭房间
        if (room.hostId === playerId) {
            const updatedRoom = await roomManager.getRoom(roomId);
            if (updatedRoom && updatedRoom.players.length > 0) {
                // 转让给第一个玩家
                await roomManager.transferHost(roomId, updatedRoom.players[0].playerId);
                io.to(roomId).emit('HOST_TRANSFERRED', {
                    newHostId: updatedRoom.players[0].playerId,
                    room: await roomManager.getRoom(roomId)
                });
            } else {
                // 删除空房间
                await roomManager.deleteRoom(roomId);
            }
        }
        
        // 广播房间列表更新
        io.emit('ROOM_LIST_UPDATE', { 
            rooms: await roomManager.getAvailableRooms() 
        });
    } catch (error) {
        console.error('处理玩家离开失败:', error);
    }
}
```

```javascript

class RoomManager {
    constructor() {
        this.client = redis.createClient();
        this.client.connect();
    }
    
    // 生成房间号
    generateRoomId() {
        const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
        let roomId = '';
        for (let i = 0; i < 6; i++) {
            roomId += chars.charAt(Math.floor(Math.random() * chars.length));
        }
        return roomId;
    }
    
    // 创建房间
    async createRoom(data) {
        const roomId = this.generateRoomId();
        const room = {
            roomId,
            roomName: data.roomName,
            hostId: data.hostId,
            hostName: data.nickname,
            players: [{
                playerId: data.hostId,
                nickname: data.nickname,
                ready: true,
                isHost: true,
                laneIndex: 0
            }],
            maxPlayers: data.maxPlayers,
            difficulty: data.difficulty,
            status: 'waiting',
            words: [],
            gameState: {
                startTime: null,
                playerProgress: {}
            },
            createdAt: Date.now()
        };
        
        await this.client.set(`room:${roomId}`, JSON.stringify(room));
        await this.client.sAdd('rooms:active', roomId);
        
        return room;
    }
    
    // 获取房间
    async getRoom(roomId) {
        const data = await this.client.get(`room:${roomId}`);
        return data ? JSON.parse(data) : null;
    }
    
    // 获取所有可用房间
    async getAvailableRooms() {
        const roomIds = await this.client.sMembers('rooms:active');
        const rooms = [];
        
        for (const roomId of roomIds) {
            const room = await this.getRoom(roomId);
            if (room && room.status === 'waiting') {
                rooms.push(room);
            }
        }
        
        return rooms;
    }
    
    // 添加玩家到房间
    async addPlayerToRoom(roomId, playerData) {
        const room = await this.getRoom(roomId);
        if (!room) throw new Error('房间不存在');
        
        room.players.push(playerData);
        await this.client.set(`room:${roomId}`, JSON.stringify(room));
    }
    
    // 从房间移除玩家
    async removePlayerFromRoom(roomId, playerId) {
        const room = await this.getRoom(roomId);
        if (!room) return;
        
        room.players = room.players.filter(p => p.playerId !== playerId);
        
        if (room.players.length === 0) {
            await this.deleteRoom(roomId);
        } else {
            await this.client.set(`room:${roomId}`, JSON.stringify(room));
        }
    }
    
    // 切换准备状态
    async togglePlayerReady(roomId, playerId) {
        const room = await this.getRoom(roomId);
        if (!room) throw new Error('房间不存在');
        
        const player = room.players.find(p => p.playerId === playerId);
        if (player && !player.isHost) {
            player.ready = !player.ready;
            await this.client.set(`room:${roomId}`, JSON.stringify(room));
        }
    }
    
    // 开始游戏
    async startGame(roomId, words, startTime) {
        const room = await this.getRoom(roomId);
        if (!room) throw new Error('房间不存在');
        
        room.status = 'playing';
        room.words = words;
        room.gameState.startTime = startTime;
        
        // 初始化每个玩家的进度
        room.players.forEach(player => {
            room.gameState.playerProgress[player.playerId] = {
                completedWords: 0,
                correctCount: 0,
                wrongCount: 0,
                currentWordIndex: 0,
                finishTime: null,
                rank: 0
            };
        });
        
        await this.client.set(`room:${roomId}`, JSON.stringify(room));
    }
    
    // 更新玩家进度
    async updatePlayerProgress(roomId, playerId, progress) {
        const room = await this.getRoom(roomId);
        if (!room) return;
        
        room.gameState.playerProgress[playerId] = {
            ...room.gameState.playerProgress[playerId],
            ...progress
        };
        
        await this.client.set(`room:${roomId}`, JSON.stringify(room));
    }
    
    // 记录完成
    async recordFinish(roomId, playerId, finishData) {
        const room = await this.getRoom(roomId);
        if (!room) return;
        
        room.gameState.playerProgress[playerId].finishTime = finishData.finishTime;
        room.gameState.playerProgress[playerId].stats = finishData.stats;
        
        // 计算排名
        const finishedPlayers = Object.values(room.gameState.playerProgress)
            .filter(p => p.finishTime)
            .sort((a, b) => a.finishTime - b.finishTime);
        
        const rank = finishedPlayers.length;
        room.gameState.playerProgress[playerId].rank = rank;
        
        await this.client.set(`room:${roomId}`, JSON.stringify(room));
        
        return rank;
    }
    
    // 检查是否所有人完成
    async checkAllFinished(roomId) {
        const room = await this.getRoom(roomId);
        if (!room) return false;
        
        return Object.values(room.gameState.playerProgress)
            .every(p => p.finishTime !== null);
    }
    
    // 重置房间
    async resetRoom(roomId) {
        const room = await this.getRoom(roomId);
        if (!room) return;
        
        room.status = 'waiting';
        room.words = [];
        room.gameState = {
            startTime: null,
            playerProgress: {}
        };
        room.players.forEach(p => {
            p.ready = p.isHost;
        });
        
        await this.client.set(`room:${roomId}`, JSON.stringify(room));
    }
    
    // 转让房主
    async transferHost(roomId, newHostId) {
        const room = await this.getRoom(roomId);
        if (!room) return;
        
        room.players.forEach(p => {
            p.isHost = p.playerId === newHostId;
            if (p.isHost) {
                p.ready = true;
            }
        });
        
        room.hostId = newHostId;
        await this.client.set(`room:${roomId}`, JSON.stringify(room));
    }
    
    // 删除房间
    async deleteRoom(roomId) {
        await this.client.del(`room:${roomId}`);
        await this.client.sRem('rooms:active', roomId);
    }
}

module.exports = RoomManager;
```
